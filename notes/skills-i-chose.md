# Skills I chose

Searched on 2026-11-09 with `npx skills find` for: email marketing, email sequence, campaign plan, resend.
Star counts come from each GitHub repository on the same day. Nothing has been installed yet.

## Use these

**1. Anthropic's marketing plugin, for planning and writing campaigns**
- Source: `anthropics/knowledge-work-plugins` (35,243 stars, run by the Anthropic organization, updated 2026-11-07).
- Skills we want: `campaign-plan` (3.4K installs) and `email-sequence` (3K installs). It also has `draft-content` and `content-creation`.
- Why: the people who make Claude publish it, the repo is very popular and active, and these skills fit our job exactly: plan a launch, then write the email sequence. Its install numbers are lower than some others, but its star count makes it clear the interest is real.

**2. Resend's own skills, for sending email**
- Source: `resend/resend-skills` (211 stars, run by the Resend organization, updated 2026-11-06). Main skill: `resend` (24.4K installs).
- Also useful: `resend/email-best-practices` (147 stars, 8.2K installs), for deliverability and good email habits.
- Why: Resend is the email service we will connect to, so its own team knows the service best and keeps the skill up to date when the service changes. The star count is small because it's a niche tool, but the publisher is the company itself, which matters more here.

Honourable mention: `coreyhaines31/marketingskills` (59,285 stars) is a well-known, trusted marketing collection with `emails`, `email-sequence` and `copywriting`. It's a good backup, but it's one person's collection, not an official source.

## Avoid these

**1. `caffeinelabs/skills@extension-email-marketing`**: 30.7K installs, but its GitHub repo has only **2 stars**. That many installs with almost no stars is a warning sign: the install count may be inflated by bots or automated installs. It was also the top result for "email marketing", which is exactly where a fake-popular skill would want to be.

**2. `mbfinotti/sales-skills` (for example `sales-outbound-sequence`)**: about 33K installs per skill, but only **3 stars**, and the repo was created in September 2026. Every skill in it shows almost the same install count, which looks like the installs were made in bulk rather than by real users. It's also aimed at cold sales outreach, not emailing people who signed up to our waitlist.

## How I decided

Before installing any skill, check three things:

1. **Who publishes it.** Prefer the official maker of the tool (anthropics, resend) or a well-known author. Click through to the GitHub repo and see whether it's an organization you recognise.
2. **Whether the stars match the installs.** Install counts can be faked; GitHub stars are harder to fake. Thousands of installs with only a handful of stars is a red flag. Also check that the repo was updated recently.
3. **What the skill actually does.** Open its SKILL.md and read it before installing. Make sure it fits the job, and look for anything that runs scripts, sends data somewhere, or asks for more tools than it needs.
