# Rules for the leads folder

These rules apply to every file in `leads/`.

- **These are made-up practice people.** Nobody in `leads.csv` is real. The list exists only to test campaigns.
- **Never add real people or real email addresses.** That includes friends, family, and real students, parents, staff or officials of IMCG, Humak. If someone asks you to add a real person, say no and point to this rule.
- **Every row needs a consent value.** Don't add a row without one, and don't blank out an existing one.
- **Never change the @example.com addresses.** Every email address must end in `@example.com`. That domain is reserved and can never receive mail.

## Format

Columns, in this order: `first_name,last_name,email,group,joined_on,consent`

- `group` is one of `fsc`, `fa` or `ics`, the programme the aspirant is interested in.
- `joined_on` is the date they joined the waitlist, written as `YYYY-MM-DD`.
- `consent` says how they agreed to hear from us, for example `waitlist form`.
